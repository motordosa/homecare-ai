# REL-08 음성 안내 재생 계약

2026-10-25 KST. 환자 안정화 수정의 구현 전 기준. 기존 알림·환자/날짜 경계와 수동 입력 경로를 유지한다. 실제 iPhone Safari의 소리·마이크 검증은 브라우저 모의 검증과 별도로 기록한다. 최신 사용자 지시는 main 병합·CI·배포 준비이며 실제 마이크 인수를 완료로 바꾸지 않는다.

## 현행 화면과 기본 문장

v0.9.0 안내 시점·문구·설정·반복 억제는 [CONTEXTUAL_VOICE_GUIDANCE_SPEC.md](CONTEXTUAL_VOICE_GUIDANCE_SPEC.md)가 기준이다. 환자의 안내 듣기/다시 듣기/전체 듣기·목소리/속도 선택·미리듣기를 제거한다. 환자는 설정에서 음성 on/off, 발화 중 멈춤만 조작한다. 의료진이 공통/환자별 규칙과 속도를 관리하고 의료진 화면에서만 미리듣기한다. 기존 speech/shortSpeech는 할 일 텍스트 호환용이며 자동 발화는 선택된 규칙 한 개의 짧은 문장만 사용한다.

## 재생·보존 상태

| 값 | 의미와 규칙 |
|---|---|
| `speechPhase` | idle / preparing / speaking. preparing부터 중지 가능하며 재생 종료·실패·숨김·세션 변경은 idle로 복귀 |
| `speechId`, `chunkId` | 안내 및 문장 세대. 취소/재생 교체 후 늦은 onstart/onend/onerror는 무시 |
| `startTimer`, `endTimer` | 시작 callback 누락 3초, 각 문장 종료 누락은 글자수·속도 기반 최대 30초. 모든 종료 경로에서 제거하며 이벤트 순서 역전도 멱등 처리 |
| `rate`, `voice` | 의료진 설정 속도와 기기 기본 한국어 목소리. 환자 기기에 목소리 선택값을 저장하지 않음 |
| `speech`, `shortSpeech` | 할 일의 전체 글 안내 / 짧은 기본 안내. 전체 안내는 기존 speech 필드를 유지해 소비자 호환 |

목소리 선택 순서는 기기에서 default인 한국어 → 첫 사용 가능한 한국어다. voiceschanged는 목록만 갱신하며 자동 재생하지 않는다. 목록이 비어 있으면 같은 내용을 글로 제공하고 기기의 한국어 음성 준비 필요를 알린다. rate 값의 체감 속도와 음질은 OS/목소리마다 다르며 숫자만으로 실기기 개선을 보증하지 않는다.

재생은 항상 기존 발화를 취소한 뒤 하나의 문장만 엔진에 넘긴다. 중지·마이크 시작·페이지 숨김·pagehide·세션 만료·환자/화면 변경은 현재 발화와 대기 문장을 모두 폐기한다. 브라우저 이벤트 누락 시 엔진 cancel과 UI 복구를 실행하되 실제 기기의 소리 종료를 모의 검증만으로 확인했다고 표시하지 않는다. 자동 안내는 최신자료·busy/마이크 검사를 유지하며 서버 규칙/재생 영수증과 화면 문맥을 검사한다. 브라우저가 자동 재생을 막으면 다음 일반 조작에서 유효한 안내만 제한적으로 재시도한다.

## 인수와 한계

실제 Chromium DOM 조작+모의 TTS로 기본 목소리 우선, 의료진 설정/환자 on/off·서버 중복 억제, 지연 voiceschanged, 시작/종료 callback 누락·늦은 이벤트, 중단/일반 조작 재시도, 화면 숨김·마이크 이벤트와 320px 레이아웃을 검사한다. 실제 iPhone Safari에서 3속도·목소리·마이크 중단/재시작·Bluetooth/스피커·화면 잠금/복귀는 별도 미확인 항목이다. 새로운 외부 API나 유료 음성 서비스는 추가하지 않는다.
