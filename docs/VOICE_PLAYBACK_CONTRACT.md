# REL-08 음성 안내 재생 계약

2026-10-25 KST. 환자 안정화 수정의 구현 전 기준. 기존 알림·환자/날짜 경계와 수동 입력 경로를 유지한다. 실제 iPhone Safari의 소리·마이크 검증은 브라우저 모의 검증과 별도로 기록하며 완료 전 공개 배포하지 않는다.

## 화면과 기본 문장

P-VOICE-GUIDE의 헤더 ‘안내 듣기/다시 듣기’는 짧은 인사와 현재 남은 다음 행동 1개를 읽는다. 약 일정 조회 실패는 첫 행동 대신 확인 필요 안내를 우선한다. 전체 목록은 P-TASKS의 ‘오늘 안내 모두 듣기’로 선택한다. 안내 문장은 글로도 확인할 수 있다. 전체 안내도 한 문장씩 순서대로 읽으며 중지 시 나머지 문장은 폐기한다. 기존 할 일 계산과 실제 기록/예정/미보고 의미는 바꾸지 않는다.

P-GUIDE의 음성·알림 설정에 ‘읽는 속도’(천천히 0.85 / 보통 1.0 기본 / 조금 빠르게 1.15), ‘한국어 목소리’(기기 기본 또는 해당 기기의 목록), ‘선택한 소리 들어보기’, ‘소리 멈추기’, 상태 설명을 제공한다. 선택은 자동 재생하지 않는다. 설정 변경은 재생을 멈추고 직접 미리듣기로 확인한다. 모든 조작은 큰 레이블/터치 영역을 유지하며 색만으로 상태를 구별하지 않는다. 안내를 끄면 미리듣기도 재생하지 않는다.

## 재생·보존 상태

| 값 | 의미와 규칙 |
|---|---|
| `speechPhase` | idle / preparing / speaking. preparing부터 중지 가능하며 재생 종료·실패·숨김·세션 변경은 idle로 복귀 |
| `speechId`, `chunkId` | 안내 및 문장 세대. 취소/재생 교체 후 늦은 onstart/onend/onerror는 무시 |
| `startTimer`, `endTimer` | 시작 callback 누락 3초, 각 문장 종료 누락은 글자수·속도 기반 최대 30초. 모든 종료 경로에서 제거하며 이벤트 순서 역전도 멱등 처리 |
| `speechRate`, `selectedVoiceURI` | 비민감 기기 설정만 기존 localStorage에 저장. 목록에 없는 설정은 기본 한국어 목소리로 대체했다는 글 안내. 내용·음성·환자 ID는 저장하지 않음 |
| `speech`, `shortSpeech` | 할 일의 전체 글 안내 / 짧은 기본 안내. 전체 안내는 기존 speech 필드를 유지해 소비자 호환 |

목소리 선택 순서는 유효한 사용자 지정 한국어 voiceURI → 기기에서 default인 한국어 → 첫 사용 가능한 한국어다. voiceschanged는 목록만 갱신하며 자동 재생하지 않는다. 목록이 비어 있으면 버튼을 눌렀을 때 한국어 음성 준비/설정 안내를 제공한다. rate 값의 체감 속도와 음질은 OS/목소리마다 다르며 숫자만으로 실기기 개선을 보증하지 않는다.

재생은 항상 기존 발화를 취소한 뒤 하나의 문장만 엔진에 넘긴다. 중지·마이크 시작·페이지 숨김·pagehide·세션 만료·환자/화면 변경은 현재 발화와 대기 문장을 모두 폐기한다. 브라우저 이벤트 누락 시 엔진 cancel과 UI 복구를 실행하되 실제 기기의 소리 종료를 모의 검증만으로 확인했다고 표시하지 않는다. 자동 안내는 기존 사용자 활성화·홈·최신자료·busy/마이크·탭 내 하루 1회 조건을 유지한다.

## 인수와 한계

실제 Chromium DOM 조작+모의 TTS로 기본 목소리 우선, 사용자 선택·설정 유지, 지연 voiceschanged, 시작/종료 callback 누락·늦은 이벤트·빠른 시작/중지, 전체 문장 순차 처리·중단, 화면 숨김·마이크 이벤트와 320px 큰 글자 레이아웃을 검사한다. 실제 iPhone Safari에서 3속도·목소리·마이크 중단/재시작·Bluetooth/스피커·화면 잠금/복귀는 별도 미확인 항목이다. 새로운 외부 API나 유료 음성 서비스는 추가하지 않는다.
